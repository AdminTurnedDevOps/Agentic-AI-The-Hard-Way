Claude Code and Cowork can take up:
- 300MB to 1GB of RAM
- 50-90% of CPU
- 16GB-48GB of VRAM

and at least 16GB of RAM on a macine is recommended to run Agents.

You'll see similar stats for other agent runtimes/platforms like Codex and opencode.

Because of that, you'll want a decently beefy machine to run your Agents on. I use an M4 Max mac. If you don't have a powerful VM, definitely look at solutions like Claude Managed Agents, Microsoft Foundry Managed Agents, and Codex/Workspace Agents.

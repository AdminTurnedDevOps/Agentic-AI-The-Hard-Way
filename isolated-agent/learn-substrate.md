Tldr; Agent Substrate is a method of isolating Agents (and other workloads like Web APIs) with either software isolation (gVisor) or hardware isolation (microVM).

It's an OSS project out of Google that runs on Kubernetes, but with it's on Control/Management Plan built for effective, efficient, cost centric Agents.
